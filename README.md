# TaskFlow — Todo App

A modern, responsive Todo application built with React and Vite.

## Features
- Create, edit, complete and delete tasks
- Search tasks and filter by All, Active, or Completed
- Priority levels and due dates
- Persistent data with browser LocalStorage
- Light and dark themes
- Responsive mobile and desktop interface
- Progress tracking

## Run locally
```bash
npm install
npm run dev
```

## Build for production
```bash
npm run build
```

The app is a client-side project, so tasks are stored in the browser and do not require a backend database.
